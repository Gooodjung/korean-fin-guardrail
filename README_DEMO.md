# 실행 가이드 (streamlit_demo.py)

## 1. 설치
```bash
pip install streamlit
```

## 2. 실행
프로젝트 루트(guardrail-framework 폴더)에서:
```bash
streamlit run streamlit_demo.py
```
브라우저가 자동으로 열립니다 (http://localhost:8501).

## 3. 구성
- **① 실시간 검사**: 문장을 넣으면 Layer1(정규식) → Layer2(NER) → Layer3(LLM) 순서로 판정하고, 어느 레이어에서 왜 막혔는지 보여준다. 예시 문장 7개가 준비되어 있다.
- **② 자동 튜닝(실시간 모드)**: 현재 배포된 가드레일이 실제로 놓치는 공격 문장 3개가 준비되어 있다(공격 데이터셋에서 확인된 사례). 운영 중 발생한 공격 문장 1건에 즉시 대응하는 흐름으로, 배치 모드(전체 데이터셋 재평가 + McNemar 통계 게이트)와는 별개다. ①문장 발생 → ②실패 샘플 등록 → ③AI가 새 판단 기준 제안 → ④반영 후 같은 문장 재확인 → ⑤누적 회귀 코퍼스 검사(McNemar 대신 사용 — 문장 1건으로는 통계 검정이 성립하지 않기 때문) → ⑥두 조건(문장 차단 + 회귀 없음)을 모두 만족해야 채택, 아니면 반려하고 담당자 검토로 넘긴다.
- **③ 오탐 완화**: 정상 문장인데 잘못 차단되는 사례(마스킹된 주민등록번호·카드번호)를 넣고, ① 검사 → ② AI가 SAFE 예외를 제안 → ③ 반영 후 재검증하는 흐름이다.

## 4. 참고
- 사이드바에서 현재 판단 기준 항목 수, SAFE 예외 수, 누적 회귀 코퍼스 건수를 확인할 수 있고, "초기화"로 언제든 처음 상태로 되돌릴 수 있다.
- 실시간 모드에서 채택된 패치는 세션 안에서만 규칙·회귀 코퍼스에 누적되며, 디스크에 있는 원본 규칙 파일·회귀 코퍼스 파일은 시연 전후로 동일하게 유지된다.
